## 2. 核心功能模块（视频批处理）

| 模块 Key | 名称 | 用户价值 | 状态 |
|----------|------|----------|------|
| `cut` | 视频裁切 | 固定时段 / 末尾 N 秒；保留或删除区间 | ✅ |
| `ratio` | 比例适配 | 如 9:16 模糊铺底等 | ✅ |
| `mov_wm` | AE 透明 MOV 水印 | 循环贴片水印、时长/位置 | ✅ |
| `png_wm` | PNG 静态水印 | 全屏/定点、时段 | ✅ |
| `layer` | 浮层落版 | 结尾覆盖落版；音画对齐 | ✅ |
| `ending` | 拼接落版（旧版） | 拼到主片末尾；可截取落版前 N 秒 | ✅ |
| `overlay` | 可视化叠加 | 画布编辑器批量叠图/组合 | ✅ |
| （历史） | 替换音频 / 动态文字水印 | 早期能力；文字水印已移除 | 🗄 |

| 同名处理 | 自动改名 / 覆盖 / 跳过 | ✅ |
| 实时预览（短片） | 智能/前/中/尾 3 秒试跑 | ✅ |
| 预览画布 | 抽帧 + 水印/比例示意框（V22+） | ✅ |

| 撤销上次批处理 | 备份回滚（V18+ 能力线） | ✅ |
| 处理日志 | 彩色模块日志、失败列表 | ✅ |
| 年度工具年报 | 使用统计展示（V22） | 🧪 |
