# 飞跃视频批处理工具 · 使用说明书

> 适用版本：**V24 工作台**（批处理 + 规范命名 + 批量裂变）  
> 更新：2026-08

---

## 一、软件是做什么的？

飞跃视频批处理工具面向**素材团队批量出片**，在一套界面里完成：

| 能力 | 说明 |
|------|------|
| **视频批处理** | 对文件夹内视频批量裁切、改比例、加水印/落版、叠加、字幕等 |
| **规范命名** | 按品牌/语言/序号等规则，统一改文件名 |
| **批量裂变** | 同一批素材，一次跑出多套不同方案（多水印/多落版组合） |

**典型路径：** 选素材 → 套方案 → 开始处理 → 规范命名 → 交付。

---

## 二、启动与安装

### Windows（推荐）

1. 解压 `飞跃视频工具_Windows` 文件夹  
2. 双击 **`飞跃视频工具.exe`** 启动主程序  
3. 可选：双击 **`飞跃命名工具.exe`** 单独打开命名工具（主程序内也可切换）  
4. **无需安装 Python**；完整包已内置 FFmpeg  

**字幕（SRT）功能（可选）：**  
在发布文件夹运行 **`setup_subtitle_env.bat`**，按提示安装 Whisper 环境，完成后重启主程序。

### macOS

1. 解压 `HabiVideoTool_macOS`  
2. **首次打开**：右键 `HabiVideoTool.app` → **打开** → 再点 **打开**（勿直接双击，可能被系统拦截）  
3. 需要字幕时，在发布目录运行 `./setup_subtitle_env_mac.sh`

### 配置文件存在哪？

| 系统 | 主程序配置 | 命名工具配置 |
|------|------------|--------------|
| Windows | exe 同目录 `video_batch_config_*.json` | `%APPDATA%\HabiNamingTool\` |
| macOS | `~/Library/Application Support/HabiVideoTool/` | Application Support 对应目录 |

> 升级 exe **不会**覆盖你的方案和命名预设；方案模板在 `templates` 文件夹（与程序同目录或工程目录）。

## 三、界面总览

顶栏三个标签页：

```
┌─────────────────────────────────────────────────────────┐
│  [ 视频批处理 ]  [ 规范命名 ]  [ 批量裂变 ]              │
└─────────────────────────────────────────────────────────┘
```

**视频批处理** 为三栏布局：

| 区域 | 作用 |
|------|------|
| **左栏** | 输入源、方案模板、功能勾选、常用素材、预览快捷 |
| **中栏** | 流水线条、视频预览、各功能详细设置 |

| **底部** | 当前方案名、已启用功能数、进度、**设置** |

## 四、视频批处理 · 快速上手

### 4.1 五步出片

1. **选输入文件夹**（左栏，或拖入文件夹）  
2. **选方案模板**（左栏下拉 → 点「加载」）  
3. **勾选需要的功能**（左栏功能清单；新勾选的会置顶到中间设置区）  
4. **设输出文件夹**（右栏）  
5. 点右栏底部 **「开始处理」**

处理过程中可 **暂停 / 停止**；日志区会显示进度与报错。

### 4.2 流水线顺序

默认处理顺序（可在流水线条里 **调整顺序**）：

```
视频裁切 → 比例适配 → 动态水印 → 静态水印 → 浮层落版 → 拼接落版 → 可视化叠加 → 字幕
```

只跑你**已勾选**的步骤；顺序会影响最终效果（例如先裁切再加水印）。

### 4.3 方案模板

- **加载**：从下拉选方案 → 点「加载」，参数与勾选一并恢复  
- **保存**：调好参数后点「保存」，输入名称写入 `templates`  
- **删除**：选中后点「删」  

> 每个方案独立保存，互不影响。切换方案后请点「加载」确认界面已切换。

### 4.4 常用素材库

- 点 **「＋ 导入素材」** 把 PNG/MOV 等收进库  
- 在资产卡片上可 **一键套到** 水印、落版、叠加等位置  
- 模式：**复制进软件** 或 **只引用原路径**

### 4.5 预览

- 中栏预览画布可查看当前帧、拖拽时间轴  
- 左栏可选预览时段：智能 / 前 3 秒 / 结尾 3 秒 / 中间 3 秒  
- 双击预览可放大

## 五、各功能说明

### 5.1 视频裁切

- **固定时段**：保留或删除指定开始～结束时间  
- **末尾 N 秒**：只处理视频最后若干秒  

适合去片头片尾、抽片段。

### 5.2 比例适配

- 目标比例：9:16、4:5、1:1、16:9 等  
- **背景模糊填充**：竖屏素材转横屏时铺底  

### 5.3 动态水印（AE 透明 MOV）

- 选择 **带 Alpha 的 MOV** 循环水印  
- **全屏贴合** 或 **自定义位置**（可点「预览并定位」拖拽）  
- **持续秒**：0 表示全程  
- **颜色保护**：减轻透明 MOV 缩放后发灰/发黑（略慢，建议透明水印开启）

### 5.4 静态水印（PNG）

- PNG/JPG 全屏或定点  
- 可设 **显示时段**（全程或指定秒段）

### 5.5 浮层落版

- **结尾覆盖落版**：在主视频结尾前 N 秒开始叠加落版（可拖时间轴）  
- 可调尺寸%、位置  
- 可选 **保留落版音频**（与主片重叠段混合）

### 5.6 拼接落版

- 把落版 **拼接到主视频末尾**（与浮层落版不同）  
- 可截取落版前 N 秒再拼接  

### 5.7 可视化叠加

- 打开 **叠加编辑器**，管理底图 / 视频 / Logo 多层  
- 支持单条视频单独定位、缩放、时段  
- 复杂组合建议在此编辑，保存进方案模板  

### 5.8 字幕

两种模式（二选一）：

| 模式 | 用途 |
|------|------|
| **AI 识别/翻译 → SRT** | 本地 Whisper 识别语音，导出 `.srt`（可选翻译、双语） |
| **外部 SRT → 烧录** | 用剪映/PR 导出的 SRT，烧录进视频 |

**外部 SRT 来源：** 与视频同目录同名 / 指定文件夹 / **固定 SRT（应用到所有视频）**

> 字幕需先安装 Whisper 环境（见第二节）。国内网络下机器翻译可能不稳定，建议仅出 SRT 后人工校对。

## 六、规范命名

切到顶栏 **「规范命名」**。

### 6.1 基本流程

1. **选择文件夹**（一般为批处理/裂变输出目录）  
2. 是否勾选 **「含子文件夹」**（默认**不勾选**；多方案输出在子文件夹里时再勾）  
3. 点 **「扫描」** 预览新旧文件名  
4. 确认后 **「执行重命名」**

### 6.2 命名模板

模板由多段组成，可插入变量，例如：

- `{index}` 序号  
- `{brand}` 品牌  
- `{lang}` 语言  
- `{type}` 类型  
- `{tag1}` `{tag2}` `{tag3}` 标签  
- `{size}` 尺寸  
- `{date}` 日期  
- `{designer}` 设计师  

可在「字段设置」里维护各字段的下拉选项和标签库。

### 6.3 高级规则

可展开 **高级规则链**：添加补齐、替换、删除、移动、大小写、旧版标签清理等。

### 6.4 与批处理联动

- 批处理/裂变完成后，可提示跳转命名页  
- 右栏也有 **「切换到命名页」** 快捷入口

## 七、批量裂变

切到顶栏 **「批量裂变」**。适合 **同一批素材一次跑出多套方案**。

### 7.1 概念

```
输入文件夹 → [可选：预处理] → 方案 A / 方案 B / 方案 C … → 各方案单独输出子文件夹
```

- **单源**：一个输入夹，多个方案并行输出  
- **多源**：多个「源组」，每组独立输入/输出/预处理，**组与组串行**执行  

### 7.2 操作步骤

1. 设 **输入文件夹** 与 **输出根目录**  
2. 在画布 **双击空白** 或点添加 → 引用已有方案模板 / 新建方案  
3. 每个方案可勾选裁切、水印、落版等功能，并 **调整顺序**  
4. 点子功能可设细节（与批处理参数一致）  
5. 可选 **预处理**：先用某套模板整批过一遍，再进各裂变方案  
6. 点 **「开始处理」**

输出结构示例：

```
输出根/
  方案A/
    001.mp4
  方案B/
    001.mp4
```

### 7.3 视图

- **思维导图 / 地铁线路**：可视化方案关系  
- **列表**：表格管理分支（适合习惯 Excel 的用户）

### 7.4 重编号

裂变完成后，若需接共享盘序号，可使用 **「重编号」** 功能。

> 裂变方案暂 **不含字幕** 步骤；需字幕请在批处理单方案中处理，或预处理模板里启用。

## 八、生产队列与监视文件夹

### 8.1 生产队列

- **＋批处理** / **＋裂变**：把当前配置加入队列  
- **开始队列**：按顺序自动跑完  
- 可设失败 **重试次数**（0～3）  
- 支持 **暂停 / 停止**

### 8.2 监视文件夹

- 指定 **监视目录** 和 **输出根**  
- **扫描入队**：把现有子文件夹加入队列  
- **开始监视**：定时检测新子文件夹，自动入队  

适合无人值守、多批次素材陆续到达的场景。

## 九、设置（偏好）

点底部 **「设置」** 可配置：

| 项 | 说明 |
|----|------|
| 默认打开页 | 启动时进批处理 / 命名 / 裂变 |
| 自动加载方案 | 启动时加载上次或指定模板 |
| 界面皮肤 | 简约工作台 / 奶油 / 蓝 / 绿 / 暗色等 |

| 裂变完成后提示命名 | 跑完自动询问是否去规范命名 |

## 十、典型工作流示例

### 场景 A：日常单方案批处理

1. 加载方案「habi11」  
2. 输入素材夹 → 输出夹  
3. 确认水印/落版路径 → 开始处理  
4. 切规范命名 → 扫描 → 执行重命名  

### 场景 B：同一批素材多套水印

1. 打开 **批量裂变**  
2. 引用模板 A、B、C 三个方案  
3. 设输出根 → 开始处理  
4. 命名页勾选 **「含子文件夹」** 再扫描  

### 场景 C：夜间无人值守

1. 监视文件夹指向素材投递目录  
2. 队列加入批处理或裂变任务  
3. 开始监视 + 开始队列

## 十一、常见问题

| 现象 | 处理 |
|------|------|
| 双击 exe 无反应 / 闪退 | 右键 exe → 以管理员运行；查杀毒是否拦截；看同目录是否有日志 |
| 提示找不到 FFmpeg | 使用完整发布包；或将 `ffmpeg.exe` 放 exe 同目录 |
| 界面是灰色丑皮 | 重新安装带 tttbootstrap 的完整包 |
| 拖文件夹无效 | 用「选择文件夹」按钮；Windows 可装 windnd |
| 处理很慢 / 像卡住 | 看日志是否出现「编码中」；全屏静态水印/大分辨率会慢，属正常 |
| 同名文件冲突 | 弹窗选择：跳过 / 覆盖 / 自动重命名 |
| 切换方案后参数不对 | 点「加载」模板；各方案独立，勿混淆 |
| 命名扫不到子文件夹里的片 | 勾选 **「含子文件夹」** 再扫描 |
| 字幕只有 1 条或失败 | 先运行 `setup_subtitle_env`；检查模型与路径 |
| Mac 打不开 | 右键 App → 打开；或终端 `xattr -cr *.app` |
