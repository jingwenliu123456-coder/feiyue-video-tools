# Flows — 关键用户旅程

> Skill: `shipping-artifacts` · 只收录触及文件完整性、覆盖策略、外置 FFmpeg 副作用的流程。

---

## F1. 标准批处理出片

| | |
|--|--|
| **Actor** | 素材设计师 |
| **Precondition** | 已选输入/输出文件夹；至少启用一个管线步骤；FFmpeg 可用 |
| **Success** | 输出目录得到成片；日志无未处理失败（或失败列表可复查） |

**步骤**

1. 选择输入文件夹 → 扫描视频列表  
2. 选择输出文件夹 + 同名策略（改名/覆盖/跳过）  
3. （可选）加载方案模板 → 应用开关与参数  
4. 勾选/配置：裁切、比例、MOV/PNG 水印、浮层/拼接落版、可视化叠加  
5. （可选）预览画布抽帧确认位置  
6. 开始批处理 → 按管线逐步 FFmpeg → `safe_publish` 到输出  
7. （可选）打开命名工具 / V24 切到命名 Sheet，对输出文件夹规范改名  

**副作用**：写输出文件；可能写备份/临时预览目录；写配置 JSON。  
**失败态**：单文件失败记入 `failed_files`，不应默默覆盖已有好片（取决于 conflict_mode）。

## F2. 方案模板保存 / 加载

| | |
|--|--|
| **Actor** | 设计师 / 规范管理员 |
| **Success** | 模板列表可选；加载后界面与批处理行为一致 |

**步骤**：调参 → 保存为模板 JSON → 他人/下次加载 →（询问）沿用模板路径 / 清空 / 保持当前路径。  

**风险**：旧模板字段触发已删回调；加载后 UI 未刷新（V24 已用 `_after_config_loaded` 缓解）。

---

## F3. 浮层落版（音画）

| | |
|--|--|
| **Actor** | 设计师 |
| **Success** | 结尾覆盖落版画面正确；音频符合「主片有声/无声」规则 |

**规则摘要**（实现于 `core/overlay_processor.py`）：

- 主片无声 + 落版有声 → **必须**出落版音  
- 主片有声 + 勾选保留 → 重叠段混音  
- 对齐：`setpts` + `adelay`，避免 `-itsoffset`  

---

## F4. 规范命名

| | |
|--|--|
| **Actor** | 设计师 |
| **Precondition** | 文件夹内有媒体；模板字段合法 |
| **Success** | 预览列表正确；执行改名后文件符合共享盘规则 |

**步骤**：选文件夹 → 配品牌/语言/类型/标签… → 预览 →（可选）旧版清理保留词/剔除词 → 执行改名。  

**V24 闭环**：优先带入 **输出文件夹**，避免仍指向输入源。

---

## F5. 裂变连跑（V23）

| | |
|--|--|
| **Actor** | 需要多方案产能的设计师 |
| **Success** | 每个分支在 `{输出根}/{分支名}/` 产出一套成片 |

**步骤**：编辑裂变表（每行一模板）→ 开始裂变 → 顺序加载配置并批处理 →（可选）重编号接共享盘序号。

---

## F6. 跨平台打包分发

| | |
|--|--|
| **Actor** | 维护者 / Mac 同事 |
| **Success** | Win exe 或 Mac app 可启动、可写配置、可找到 FFmpeg |

**注意**：Windows zip ≠ Mac 修复；Mac 需本机重打 app。配置目录见 `variables.md`。

## F7. V24 工作台联动（UX）

| 动作 | 期望 |
|------|------|
