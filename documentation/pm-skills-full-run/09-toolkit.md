## privacy-policy

### 适用边界（诚实声明）

飞跃视频工具与飞跃命名工具是 **仅供组织内部使用的桌面应用程序**，不是面向公众的在线服务。本「政策」描述 **数据处理实践与适用边界**，不构成面向消费者的完整法律文本；若未来对外商业化，须另行委托法务审查。

### 1. 我们是谁

- **产品**：飞跃视频工具、飞跃命名工具、V23 裂变、V24 工作台（实验）  
- **性质**：内部生产力软件，通常由团队维护者构建并通过 U 盘/网盘/内部分发

### 2. 我们收集哪些数据

| 数据类型 | 是否上传云端 | 说明 |
|----------|--------------|------|
| 视频/图片/音频文件 | **否**（默认） | 仅在本机用户选定目录读写 |
| 文件名与路径 | **否**（默认） | 用于批处理与命名；留于本机 |
| 方案模板 JSON | **否**（默认） | 用户配置目录 |
| 批处理日志 | **否**（默认） | 界面与可选本地日志文件 |
| 使用统计（年报） | **否**（默认） | V22 实验功能，本地汇总 |
| 账号/手机号/邮箱 | **不收集** | 无账号体系 |

**我们不运营中央服务器存储您的素材。**

### 3. 数据存储位置

| 平台 | 配置与模板典型路径 |
|------|---------------------|
| Windows | 用户配置目录（见 variables.md / 应用设置） |
| macOS | `~/Library/Application Support/HabiVideoTool/` |

输出文件写入 **用户自行选择的输出文件夹**（含网络映射盘时由操作系统负责权限）。

### 4. 第三方组件

- **FFmpeg / FFprobe**：本地子进程处理媒体，不向厂商发送用户文件  
- **Python / Tkinter / PyInstaller**：运行时依赖，无默认外联

### 5. 用户权利（内部语境）

- 删除数据：自行删除输出目录与配置 JSON  
- 导出：模板与配置文件可直接复制  
- 疑问：联系内部维护者而非「隐私邮箱」（未设立）

### 6. 安全说明

- 软件以 **当前 Windows/macOS 用户权限** 读写文件；请勿在不可信来源运行篡改过的 exe  
- 批处理日志可能含 **完整 FFmpeg 命令行**（含路径），分享日志时注意脱敏

### 7. 变更

内部版本更新时，若新增外联（如崩溃上报、云模板），须 **更新本文档并默认 opt-in**。

### 8. 不适用场景

- 欧盟 GDPR 正式合规声明（无跨境 SaaS）  
- 应用商店公开上架隐私标签（当前未上架）
