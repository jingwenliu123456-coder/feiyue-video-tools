## north-star-metric

### Business Game 分类

**Productivity Game（生产力型）** — 用户价值 = 更高效完成投放成片批处理与规范交付。

### North Star Metric（推荐）

> **周成功批处理出片数（Weekly Successful Batch Outputs）**

| 准则 | 是否满足 |
|------|----------|
| 易理解 | ✅ 「这周工具帮团队出了多少条合格成片」 |
| 以客户（用户）为中心 | ✅ 反映产能价值，非收入 |
| 可持续 | ✅ 习惯化使用后稳定 |
| 对齐愿景 | ✅ 「批量出片、规范命名、一次交盘」 |
| 可量化 | ✅ 日志/统计可埋点 |
| 可行动 | ✅ 产品、模板、文档均可影响 |
| 领先指标 | ✅ 团队交付效率先行 |

**定义**：一周内通过飞跃视频工具批处理完成、未人工撤销且输出文件有效的视频条数（可按用户/团队聚合）。

**Revenue 作 NSM**：**N/A** — 无对外售卖；收入不反映用户价值。

### Input Metrics（3–5 个）

| Input Metric | 与 NSM 关系 | 短期可操作 |
|--------------|-------------|------------|
| **周活跃批处理用户数（WAU-Batch）** | 人数 × 频次 → 出片数 | ✅ 内部推广 |
| **模板加载次数 / 周** | 模板降低失败、提高 repeat | ✅ 模板库 |
| **批处理成功率** | 失败不计入 NSM | ✅ ffmpeg_safe、预览 |
| **新用户 30min 激活率** | 扩大 WAU | ✅ onboarding |
| **命名工具对接输出目录次数 / 周** | 闭环 → 减少返工重批 | ✅ V24 Sheet / 快捷入口 |

## positioning-ideas

### Step 1：竞争格局摘要

| 竞争者 | 定位角度 | 缺口 |
|--------|----------|------|
| Premiere Pro | 专业剪辑 | 缺投放批处理 + 命名 |
| 剪映 | 快剪 + 模板消费 | 缺企业命名与工序链 |
| FFmpeg 脚本 | 极客自动化 | 缺 UI 与协作 |
| 手工 + Excel | 零成本 | 不可扩展、高错误率 |
| 通用转码工具 | 格式转换 | 无落版/水印业务逻辑 |

## value-prop-statements

基于 UVP：「方案模板一次配好，文件夹拖进去就出片 — 专为投放素材批处理。」

### 面向投放素材设计师

> 飞跃视频工具让投放素材设计师**不用在 Premiere 里重复裁切、套 9:16、贴水印和落版**，只需加载团队方案模板、选好文件夹，即可批量产出带品牌标准的成片。V22 预览画布帮你在批处理前对齐位置，减少整批返工。

### 面向设计负责人 / 规范管理员

> 飞跃把团队的成片工序和命名规范**固化成可分发、可版本化的模板**，新人上手从「跟人学」变成「跟模板学」。独立命名工具支持字段化命名、标签库和旧版文件名清理，让共享盘里的文件可检索、不覆盖。

### 面向 Mac 协作者

> 飞跃在 Mac 与 Windows 上运行**同一套批处理逻辑与模板**，内置 FFmpeg、配置写入 Application Support，输出文件与 Win 同事共用同一命名规则，直接进共享盘协作。

### 面向 IT / 行政分发者

> 飞跃以 PyInstaller 打包为独立 exe/app，**内置 FFmpeg、无需用户自行配环境**，双击即可启动。配对命名工具 exe，适合 U 盘/网盘在内网分发给素材团队。

### 面向大促多方案场景（V23 裂变）

> 当同一批素材需要连跑多语言、多尺寸、多落版组合时，飞跃裂变模式**按分支模板一次跑完**，输出到分目录并可选接共享盘序号，避免反复手换模板。

### 面向工作台尝鲜用户（V24）

> 飞跃工作台将视频批处理与规范命名收进**同一窗口**：左侧勾选工序、中间展开设置、顶栏切换命名 Sheet，处理链路可视化可点击跳转 — 在保持 V22 引擎稳定的前提下，缩短从出片到交盘的操作路径。

### 渠道变体摘要

| 渠道 | 一句话 |
|------|--------|
| 内部群公告 | 勾模板，文件夹进去就出片 — 飞跃 V22 已打包 |
| onboarding 首屏 | 10 分钟出第一条 9:16 落版片 |
| 组长培训 | 标准在模板里，不在老员工脑子里 |
| Mac 指南 | 同一模板，Application Support 写配置 |
